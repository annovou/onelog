# 一天 · 生活记录

一个自用的生活记录 App —— 记录睡眠、饮食、运动、学习、心情，然后从数据里看出规律。

包含这些东西：

| 文件 | 说明 |
|---|---|
| `PRD.md` | 产品需求文档：数据模型、字段定义、页面清单、洞察算法、AI 接口契约、导入规则 |
| `index.html` | 可点击的高保真原型（含 `styles.css` / `app.js`） |
| `native/` | Capacitor 工程，用来打包成安卓 App |
| `test/` | 无头测试脚本 |

---

## 怎么打开

双击 `index.html`，用浏览器打开即可。无需安装、无需联网、无需构建。

**想装到手机上用：**

1. 把这个文件夹传到任意静态托管（GitHub Pages、Vercel、Cloudflare Pages 都行，拖拽即可），拿到一个网址
2. 手机浏览器打开该网址
3. iOS Safari → 分享 → 添加到主屏幕；Android Chrome → 菜单 → 添加到主屏幕

之后就像原生 App 一样全屏打开，离线也能用。

> 直接用微信/QQ 把 `index.html` 发到手机是打不开的（它们不会渲染本地 HTML）。走静态托管最省事。

## 能做什么

**今天**
- 四张模块卡：睡眠 / 饮食 / 运动 / 学习，带目标进度
- 今日一句：根据你的数据自动生成的一句话
- 今日三件事：勾选待办
- 快捷记录：喝水、咖啡一键记；跑步、读书、心情、体重、日记点开表单
- 今天的记录：最近 5 条

**记录**
- 右上角 `＋`（其实在底部中间）→ 两种方式：
  - **一句话记**：`昨晚12点睡，中午吃了牛肉面，下午跑了5公里，晚上学了1小时英语` → 自动拆成 4 条，可逐条取消
  - **手动表单**：9 种类型，每种 1–4 个字段
- 支持补记「昨天 / 前天」
- 同一天记第二条睡眠会先问一句「替换还是再记一条」，避免时长被叠加成 15 小时

**时间轴**
- 按天倒序分组，可按类型筛选
- 首屏加载最近 14 天，底部可继续往前翻（用几年也不会卡）
- 点任意一条 → 编辑 / 删除
- 编辑时所有字段回填原值，可改日期，也能直接换类型（学习记成运动不用删了重建）
- 删除、编辑、新增、导入、清空都能在 toast 上点「撤销」

**洞察**
- 本周四项指标 + 与上周对比
- 睡眠 7 日柱图（带目标虚线）、情绪 7 日折线
- **一周节奏**：28 天按星期几拆分，可切换睡眠 / 情绪 / 学习 / 运动，直接告诉你哪天状态最差；还带一个「作息波动 ±X 分钟」
- 关联发现：睡眠×学习、睡眠×情绪、运动×睡眠、星期几效应、社交时差、记录习惯
- **洞察卡片可以点开**，看支撑这条结论的原始记录（哪天、什么数据），不用盲信
- 周报：4 个数字都对比「过去 4 周均值」，带近 5 周趋势图、本周最佳一天、下周可以试的一件事

**我的**
- 目标调整（睡眠 / 运动 / 学习 / 喝水 / 三餐）
- 浅色 / 深色主题
- 导出 JSON、导入 JSON、重新生成示例数据、清空

## AI 解析（可选）

默认关闭，用本地规则解析。想更聪明：**我的 → AI 造句解析 → 设置**。

兼容任何 OpenAI 格式的接口，填三个东西：

| 服务 | 接口地址 | 模型名 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` |
| OpenRouter | `https://openrouter.ai/api/v1` | 任选 |
| 本机 Ollama | `http://localhost:11434/v1` | `qwen2.5:7b` |

填完点「测试连接」，通过后打开开关。

- 密钥**只存在你自己浏览器**里
- 但你要记的那句话会发给对应服务商——介意的话就别开
- AI 挂了会自动退回本地规则，**不会让你白打一遍字**
- 部分服务不返回 CORS 头，浏览器直连会失败，换 OpenRouter 或本机 Ollama

## 导入手表数据

有两种方式。

### 1. Health Connect 自动同步（需要安卓 App）

```
华为手表 ──蓝牙──> 华为运动健康 ──> Health Sync ──> Health Connect ──> 本 App
```

装好 `native/` 的安卓版后，「我的 → Health Connect 自动同步 → 同步」，勾选授权即可。读睡眠、步数、静息心率、体重四类，重复同步不会重复写入。

这条链路**不需要华为授权**——读的是安卓系统级的 Health Connect。前置条件：手机有 Health Connect（安卓 14+ 自带），并且用 Health Sync 把华为健康的数据桥接过去。

### 2. 文件导入（保底，网页版也能用）

「我的 → 导入手表 / 健康数据」，支持 `.tcx` / `.csv` / `.json` / `.zip`。

**TCX 轨迹（跑步、骑行这种带 GPS 的活动）**：直接把 `.tcx` 丢进来，自动算出时长、距离、配速、爬升、均心率。导入后点开这条记录 →「查看详情」，能看：

- 每公里分段配速（最快那段标绿）
- 心率曲线（数据里有才显示；没有的话，安卓 App 里可以点「从 Health Connect 补心率」）
- 海拔剖面
- 轨迹图（带绘制动画，起点绿、终点红）

**华为手表（步数、睡眠、心率这些）：**

```
运动健康 App → 我的 → 隐私中心 / 数据管理 → 导出数据 → 得到 zip
```

把 zip 直接丢进导入面板，或者解压后挑里面的 csv / tcx。

面板里可以手动指定「哪一列是时间、哪一列是数值」，所以列名再乱也能导。

Garmin Connect、Zepp、Samsung Health 导出的 CSV 同理。

## 打包成手机 App

两条路，按你的网络条件选：

| 路线 | 需要 | 适合 |
|---|---|---|
| **[GitHub 云端打包](BUILD-WITH-GITHUB.md)** | 一个 GitHub 账号 | 访问不了 Google、装不上 Android Studio |
| [本机 Capacitor 构建](native/README.md) | Node + Android Studio（约 8 GB） | 网络正常，想改完立刻看到效果 |

两条路产出的是同一个 APK。App 里多了：

- 独立存储（不随浏览器清缓存消失）
- 每天 22:30 / 08:00 本地提醒
- 原生返回键、状态栏跟随主题
- Health Connect 自动同步

## 关于数据

- 全部存在浏览器的 `localStorage` 里，键名 `onelog.v1`
- **不上传、不联网、没有账号**（除非你开了 AI 解析）
- 第一次打开会生成 21 天示例数据，方便看效果；想从零开始，去「我的 → 清空全部数据」
- 清理浏览器数据会丢，记得定期「导出备份」

## 开发 / 调试

```bash
node --check app.js        # 语法

node test/smoke.js         # 渲染、统计、解析、洞察
node test/interact.js      # 点击、表单保存、编辑、撤销、删除
node test/v2.js            # AI 接口契约、CSV/ZIP 解析、导入映射
node test/insights.js      # 星期维度、规律性、缓存失效
node test/health.js        # Health Connect 样本翻译、去重、可用性
node test/tcx.js           # TCX 轨迹解析（含真实文件）
node test/dump.js          # 导出各页面 HTML
python test/check_html.py  # 校验 HTML 结构
```

浏览器控制台里可以用 `__onelog`：

```js
__onelog.state.events.length
__onelog.computeInsights()
__onelog.parseText('跑了5公里')
__onelog.parseCSV('日期,时长\n2026-11-20,450')
```

改 `app.js` 里的 `seedDemo()` 可以调整示例数据的生成逻辑；改 `styles.css` 顶部的变量可以整体换配色。

## 已知限制

- 规则解析只认常见说法（见 PRD 附录 A），复杂句子要靠 AI 解析
- AI 解析受浏览器跨域限制，取决于服务商
- 手表数据只能文件导入，做不到自动同步（华为不开放个人接口）
- 单设备，无同步
